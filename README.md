# スカイライン・テクノロジーズ 企業サイト

> **このリポジトリはテスト用に作成したものです。**
> 掲載している会社名・事業内容・導入事例・お知らせ・連絡先などはすべて架空のもので、実在の企業・団体とは関係ありません。

クラウド・AI・業務システム開発で企業のDXを支援するソフトウエア開発会社「スカイライン・テクノロジーズ（Skyline Technologies）」のコーポレートサイトです。

HTML・CSS・JavaScript をすべて `index.html` 1ファイルにまとめた静的サイトで、ビルドやサーバーは不要です。

## サイトの構成

1ページ構成で、ヘッダーのメニューから各セクションへ移動できます。

| セクション | 内容 |
| --- | --- |
| ヒーロー | キャッチコピー「テクノロジーで、ビジネスの地平線を広げる。」 |
| 私たちについて | 企業理念・姿勢の紹介 |
| 事業内容 | クラウドソリューション、AI・データ活用、業務システム開発、Web・モバイルアプリ、セキュリティ診断、運用・保守サポート |
| 数字で見るスカイライン | 実績を示す数値 |
| 導入事例 | 金融・物流・医療分野での導入事例 |
| 開発の流れ | ヒアリング → ご提案・設計 → 開発・テスト → リリース・運用 |
| お知らせ | プレスリリース・イベント情報など |
| 採用 | 採用情報への導線 |
| 会社概要 | 会社情報 |
| お問い合わせ | お問い合わせフォーム |

> **注意:** お問い合わせフォームはデモです。入力チェックと完了メッセージの表示のみを行い、実際には送信されません。

## ブラウザで表示する手順

### 方法1: ファイルを直接開く

1. エクスプローラーで `company-site` フォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザ（Chrome、Edge など）でサイトが表示されます。

既定以外のブラウザで開くときは、`index.html` を右クリックして「プログラムから開く」でブラウザを選ぶか、ブラウザのウィンドウへ `index.html` をドラッグ＆ドロップしてください。

### 方法2: コマンドで開く

`company-site` フォルダで次のコマンドを実行します。

```powershell
# Windows（PowerShell）
start index.html
```

```bash
# macOS
open index.html
```

### フォントについて

日本語フォント（Noto Sans JP）と英字フォント（Inter）は Google Fonts から読み込んでいます。オフラインで開くとフォントがブラウザの標準フォントに置き換わりますが、レイアウトや機能はそのまま利用できます。
